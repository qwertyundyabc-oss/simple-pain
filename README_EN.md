# Simple Pain (Pain Mechanic Mod)

> **This is a Minecraft mod written entirely by AI.** All Java source code, resource files, build scripts — including this very README — were generated by AI, with not a single line written by a human. Meow.

Inspired by the game *Casualties: Unknown*, this is a pain mechanic mod for Minecraft **1.20.1, 1.20.4, 1.21.1 and 1.21.11** Fabric, with identical gameplay across all versions. Taking damage accumulates "pain"; pain weakens your combat ability; when pain exceeds the limit, you enter shock and become unable to act — waiting for a teammate to rescue you, or facing death.

## Gameplay

Vanilla Minecraft has only one survival dimension: health. This mod stacks a second dimension on top of it: **pain**.

- **Damage builds pain**: Every time you take damage, pain increases based on the damage dealt (1:1 by default; lethal damage counts double).
- **Pain weakens combat**: Once pain exceeds the threshold (default 4), movement speed, attack damage and attack speed gradually decrease, up to a 50% penalty.
- **Shock**: When pain exceeds 100% of your max health, you enter shock — unable to use items, break blocks, attack or jump, forced into a swimming pose, with a pulsing red vignette, GUI shaking, darkness, and a heavy pain ambience.
- **Lethal protection**: While pain is not full, lethal damage does not kill you outright. Instead, you are locked at 1 health and the lethal portion is added to your pain at double rate — then you watch the pain slowly climb while clinging to a single heart.
- **Shock countdown**: Shock lasts about 20 seconds, followed by a roughly 20-second death countdown phase, ~40 seconds in total. If you are not rescued by then, your character is executed (not even Creative mode can save you).
- **Adrenaline**: When pain reaches 50% of max health, adrenaline triggers automatically, granting +25% to movement speed, attack damage and attack speed for 20 seconds, suppressing pain debuffs and shock. It has a 5-minute cooldown.
- **Teammate rescue**: Another player can sneak and hold right-click with an empty hand on a shocked player for about 5 seconds to rescue them. On success, the rescued player recovers 25% health and keeps 75% of their pain.
- **Pain Relief Powder**: A consumable that rapidly decays pain at 2% per second for 180 seconds.

## Crafting

**Pain Relief Powder**

- Glass Bottle × 1
- Nether Wart × 1
- Fermented Spider Eye × 1
- Glistering Melon Slice × 1

Shapeless recipe, yields 1 per craft. It can be found in the dedicated "Simple Pain" creative tab.

## Configuration

The config file is at `config/pain_mechanic.json`, shared by server and client. You can also adjust it in-game by installing Mod Menu + Cloth Config.

Main options:

| Option | Default | Description |
| --- | --- | --- |
| `damageToPainMultiplier` | 1.0 | Pain gained per point of damage |
| `lethalDamagePainMultiplier` | 2.0 | Extra pain multiplier for the lethal portion of damage |
| `maxPainMultiplier` | 2.0 | Pain cap = max health × this multiplier |
| `painDecayPerSecond` | 0.5 | Natural pain decay per second (relative to max health) |
| `painReliefDecayPerSecond` | 2.0 | Decay per second while under pain relief / adrenaline |
| `debuffThreshold` | 4.0 | Pain threshold where debuffs start |
| `debuffMaxPercent` | 50.0 | Maximum percentage of stats reduced by debuffs |
| `shockEnabled` | true | Whether the shock mechanic is enabled |
| `shockDurationSeconds` | 20 | Shock duration in seconds |
| `adrenalineThresholdPercent` | 50.0 | Pain percentage that triggers adrenaline |
| `adrenalineDurationSeconds` | 20 | Adrenaline duration in seconds |
| `adrenalineCooldownSeconds` | 300 | Adrenaline cooldown in seconds |
| `rescueEnabled` | true | Whether teammate rescue is allowed |
| `redVignetteEnabled` | true | Whether the red vignette is enabled |
| `guiPosition` | `bottom_center` | HUD pain bar position |

See `com.painmechanic.PainConfig` for the full list of options.

## Building

The repository root is the 1.21.11 source; sources for the other versions live in their respective subdirectories:

- Repo root (`src/`) → 1.21.11
- `painmod-1.20.1/` → 1.20.1
- `painmod-1.20.4/` → 1.20.4
- `painmod-1.21.1/` → 1.21.1

Requires JDK 17 (1.20.x) or JDK 21 (1.21.x) and network access (to fetch Fabric dependencies):

```bash
./gradlew build
```

Build output is placed in `build/libs/`.
