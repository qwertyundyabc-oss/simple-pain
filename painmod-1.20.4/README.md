# Simple Pain（疼痛机制模组）

> **这是一个完全由 AI 编写的 Minecraft 模组。** 全部 Java 源码、资源文件、构建脚本——包括你正在读的这份 README.md——都是 AI 生成的，没有任何一行人类手写代码。喵。

为 Minecraft 1.21.11 Fabric 设计的疼痛机制模组。受伤会累积「疼痛值」，疼痛会削弱你的战斗能力；疼痛超过上限后你会进入休克状态，无法行动，等待队友救援或迎接死亡。

## 玩法介绍

原版 Minecraft 只有「血量」一个生存维度，这个模组在此基础上叠加了第二个维度：**疼痛**。

- **受伤累积疼痛**：每次受到伤害都会按伤害量增加疼痛值（默认 1:1，致死伤害翻倍计算）。
- **疼痛削弱战斗力**：疼痛值超过阈值（默认 4）后，移动速度、攻击伤害、攻击速度会逐步下降，最多削减 50%。
- **休克**：疼痛值超过最大生命值的 100% 时进入休克——无法使用物品、破坏方块、攻击或跳跃，被强制按住游泳姿势，屏幕出现红色暗角脉动、GUI 抖动、黑暗效果，并伴随疼痛音效。
- **濒死保护**：疼痛未满时受到致命伤害不会直接死亡，而是锁 1 点生命并将致死部分按双倍计入疼痛——然后你会一边顶着 1 点血一边看着疼痛值缓慢爬升。
- **休克倒计时**：休克持续约 20 秒，之后进入约 20 秒的死亡音效阶段，总计约 40 秒。倒计时结束仍未获救，角色会被强制处死（连创造模式也无法豁免）。
- **肾上腺素**：疼痛值达到最大生命值的 50% 时自动触发，持续 20 秒内移动/攻击/攻速获得 +25% 加成，压制疼痛带来的削弱与休克；但有 5 分钟的冷却时间。
- **队友救援**：另一名玩家潜行并空手对休克中的你长按右键约 5 秒即可施救。救援成功后你恢复 25% 生命值，疼痛保留 75%。
- **止痛粉**：消耗品，使用后 180 秒内疼痛以每秒 2% 的速度快速衰减。

## 合成配方

**止痛粉（Pain Relief Powder）**

- 玻璃瓶 × 1
- 下界疣 × 1
- 发酵蜘蛛眼 × 1
- 闪烁的西瓜片 × 1

无序合成，一次产出 1 个。合成后可在模组专属创造标签页「Simple Pain」中找到。

## 配置

配置文件位于 `config/pain_mechanic.json`，服务端与客户端共用；也可以安装 Mod Menu + Cloth Config 后在游戏内调整。

主要配置项：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `damageToPainMultiplier` | 1.0 | 每点伤害转化的疼痛值倍数 |
| `lethalDamagePainMultiplier` | 2.0 | 致死伤害部分的疼痛额外倍数 |
| `maxPainMultiplier` | 2.0 | 疼痛值上限 = 最大生命值 × 该倍数 |
| `painDecayPerSecond` | 0.5 | 每秒自然衰减的疼痛百分比（相对最大生命值） |
| `painReliefDecayPerSecond` | 2.0 | 止痛/肾上腺素期间每秒衰减百分比 |
| `debuffThreshold` | 4.0 | 开始出现削弱的疼痛阈值 |
| `debuffMaxPercent` | 50.0 | 削弱最多扣除的百分比 |
| `shockEnabled` | true | 是否启用休克机制 |
| `shockDurationSeconds` | 20 | 休克持续秒数 |
| `adrenalineThresholdPercent` | 50.0 | 触发肾上腺素的疼痛百分比 |
| `adrenalineDurationSeconds` | 20 | 肾上腺素持续秒数 |
| `adrenalineCooldownSeconds` | 300 | 肾上腺素冷却秒数 |
| `rescueEnabled` | true | 是否允许队友救援 |
| `redVignetteEnabled` | true | 是否启用屏幕红色暗角 |
| `guiPosition` | `bottom_center` | HUD 疼痛条位置 |

完整配置项见 `com.painmechanic.PainConfig`。
